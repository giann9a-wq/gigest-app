# Ordine operativo consigliato

## Fase 1 - mettere in piedi l'ambiente
- creare repository Git
- creare database PostgreSQL
- creare progetto Google Cloud OAuth
- configurare variabili ambiente
- avviare app in locale

## Fase 2 - sicurezza e accessi
- schermata richieste accesso
- dashboard admin per approvare/rifiutare utenti
- gestione ruoli

## Fase 3 - anagrafiche
- CRUD personale
- CRUD mezzi/attrezzature
- CRUD commesse

## Fase 4 - diario
- form di inserimento attività
- menu unificato risorsa
- viste per giorno
- permessi modifica

## Fase 5 - scadenziario
- CRUD scadenze
- ricorrenze
- eventi da manutenzione

## Fase 6 - integrazione Google Calendar
- creazione calendario GiGEST
- tabella mappatura eventi
- sync da GiGEST verso Google
- sync da Google verso GiGEST
- gestione conflitti ultimo salvataggio
